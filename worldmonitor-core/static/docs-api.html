API Documentation

Seven endpoints behind one Rust binary. Everything a sales demo or an agent integration needs: list events, generate a country brief, subscribe to alerts, pull history.

OpenAPI 3.1 Bearer wm_… JSON over HTTPS SSE stream · Atom feed ChatGPT Actions ready Claude Agent ready

Specification

  • /openapi.yaml — the authoritative OpenAPI 3.1 contract (servers: templated to this origin).
  • /.well-known/ai-plugin.json — ChatGPT Actions plugin manifest.
  • /llms-full.txt — agent-friendly Markdown reference.

Authentication

Generate a key from Settings → API Keys on the Enterprise tier. Keys start with wm_ and are shown once at issuance.

# Both schemes are accepted — pick one.
curl -H "Authorization: Bearer wm_abc123…" https://your-host/api/history
curl -H "X-API-Key: wm_abc123…"             https://your-host/api/history

An invalid or revoked key returns 401 — never silently downgraded.

Quickstart: list events

curl

curl -s https://your-host/api/intelligence | jq '.[] | select(.severity >= 7)'

Python

import requests
r = requests.get("https://your-host/api/intelligence",
                 headers={"Authorization": "Bearer wm_abc123…"})
for ev in r.json():
    if ev["severity"] >= 7:
        print(ev["country"], ev["headline"])

Node (fetch)

const res = await fetch("https://your-host/api/intelligence", {
    headers: { Authorization: "Bearer wm_abc123…" }
});
const events = await res.json();
events.filter(e => e.severity >= 7).forEach(e =>
    console.log(e.country, e.headline));

Generate a country brief

curl -s https://your-host/api/brief \
  -H "Content-Type: application/json" \
  -d '{"country":"Ukraine","interests":["energy","cyber"]}'
# → { "country": "Ukraine", "summary": "..." }

Subscribe to alerts

# Alert on Ukraine events at severity ≥ 5
curl -s https://your-host/api/alerts \
  -H "Authorization: Bearer wm_abc123…" \
  -H "Content-Type: application/json" \
  -d '{"country":"Ukraine","threshold":5}'

Matching events are dispatched to the Slack webhook / Telegram bot configured in Settings → Notifications, de-duplicated per (user_id, event_id).

Real-time streaming

Use the Server-Sent-Events endpoint GET /api/stream for sub-second delivery of new fused batches, or the Atom feed for a pull-based application/atom+xml representation of the latest 50 events.

Wire up a ChatGPT Action

  1. In ChatGPT, open Explore GPTs → Create and add an Action.
  2. Paste the URL of the OpenAPI spec: https://your-host/openapi.yaml
  3. Choose API Key / Bearer auth and paste your wm_ key.
  4. Save. ChatGPT now lists every operation (listIntelligenceEvents, generateCountryBrief, createAlert, listAlerts, getEventHistory, …) as callable tools.

Wire up a Claude Agent

  1. Fetch https://your-host/openapi.yaml and generate tools (e.g. with anthropic's tool_runner or a lightweight OpenAPI → tools adapter).
  2. Store the wm_ key in your agent's secret store; send it on every call as Authorization: Bearer wm_….
  3. Give the agent a system prompt pointing at llms-full.txt so it knows what the service is best used for.

Rate limits

  • Free: per-IP soft limit on POST /api/brief.
  • Pro: unlimited briefs, soft cap on daily event fetches.
  • Enterprise: per-key quota (visible in response headers in a future release).

Error model

{ "error": "Invalid or revoked API key" }   // 401
{ "error": "Rate limit exceeded" }          // 429
{ "error": "That handle is taken …" }       // 409

Every error response is a { "error": string } JSON object; HTTP status carries the category.
