# engines to read its public content. Primary sources are preferred by both
# people and models; we are one. The crawler rules below are an explicit

# account endpoints) are disallowed because they return per-user data or
# server-sent events, not pages. They are not blocked for privacy by
# obscurity — the server enforces authentication.
